# Waldhund

Natur-Trainingsapp für Hunde. PWA, offline, ohne Account.

## Link (nach Pages)

https://eddylike.github.io/waldhund/

iPhone: Safari → Teilen → Zum Home-Bildschirm.  
Android: Chrome → Installieren.

## Kein fertiger App-Store-Eintrag

Dafür: Apple Developer + Xcode / Play Console + Capacitor. Ohne das kann niemand im Store anbieten.
